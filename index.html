Reinstall or recover over USB

This browser cannot reach a Choosatron

Installing over USB needs Chrome or Edge on a computer (Windows, macOS, Linux or a Chromebook). Safari, Firefox, and browsers on phones and tablets cannot talk to USB devices.

Open this page in Chrome or Edge and start again.

Use this page when a Choosatron will not start, or cannot be updated from its own web page. If its web page still works, update from the Firmware tab there instead: it is quicker and needs no cable.

You need Chrome or Edge on a computer (Windows, macOS, Linux or a Chromebook). Opera and other browsers built on Chrome usually work too. Safari and Firefox cannot install over USB, and neither can phones or tablets.

1 Choose the firmware

The recovery image, choosatron-factory.bin, from a release or a build of your own.

2 Choose what to do

3 Connect and install

  1. Connect the Choosatron to this computer with a USB-C cable. Some cables only charge; if nothing is found, try another.
  2. Press Install. The browser asks which device to use: pick the one named USB JTAG/serial debug unit (on Windows, a USB Serial Device with a COM number).
  3. Leave the cable connected until this page says it is done.
